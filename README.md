# LoRAで回答形式を学習し、学習前後を比較する(第2回演習)

Qwen/Qwen3.5-0.8B を LoRA で学習し、設定を1つだけ変えて再学習した結果を比較した。

## 変更した設定
- num_train_epochs: 21 → 10
- lr(2e-4)、lora_r(16)など、他の設定は同じ

## 結果(学習後)
| 項目 | 元の設定(21周) | 変更後(10周) |
|---|---|---|
| format_rate | 1.0 | 1.0 |
| content_rate | 0.905(21問中19問) | 0.952(21問中20問) |
| 最終loss | 0.0133 | 0.0986 |
| 学習時間 | 249秒 | 107秒 |

## 考察
num_train_epochs を21から10に減らして再学習した。format_rate はどちらも1.0で、形式は10周でも十分に身についた。content_rate は0.905から0.952に上がったが、21問中1問の差なので、周回数を減らしたほうが良いとまでは言えない。最終lossは0.0133から0.0986に上がったが、学習時間は249秒から107秒へと約4割に短縮された。lossが高くても正解率は下がらなかったことから、この課題では、長く学習しなくても形式は学べると考えられる。一方、FAQにない締切の質問を断言してしまう問題は、どちらの設定でも残った。
